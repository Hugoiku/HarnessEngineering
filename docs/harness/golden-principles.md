# 黄金原则（Golden Principles）

1. **知识优先于工作流** — 归档洞察；不依赖聊天记忆。
2. **渐进式披露** — 按 Layer A → B → C 读取；遵守查询预算。
3. **类型化知识** — 每条仅一种 type：`model` | `decision` | `guideline` | `pitfall` | `process`。
4. **摘要质量** — C 层 `summary` 须可独立理解；B 层派生，禁止手写摘要正文。
5. **不 fork Core** — 仅通过 `team-*` Skill 扩展；Team 命名尽量短（`team-excel`，非 `team-excel-analyze`）。
6. **证据优先** — run 写 evidence；archive 提取结构化条目，不倾倒原始聊天。
7. **敏感数据** — 不归档原始 PII/财务明细；仅规则与脱敏摘要。
8. **standard 下门禁硬失败** — precondition 失败即停止 run。
